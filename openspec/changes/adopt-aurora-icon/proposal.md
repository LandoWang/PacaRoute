# Adopt the Aurora icon

The approved AgentLink identity uses a slightly inverted-triangle alpaca face,
heavy neon contours, three solid nodes and dashed connections. Apply the chosen
Aurora palette consistently to the app icon and sidebar. Keep the menu-bar mark
as an adaptive monochrome template so it remains readable in light and dark mode.

The canonical vector is `apps/macos/Design/AgentLink-aurora.svg`. Native
CoreGraphics paths reproduce it without adding runtime image dependencies.
Ship separate Apple Silicon and Intel packages with bundle build 12.
