# Design

Keep bundle/data/Keychain identities while renaming visible surfaces and packages.
Replace MenuBarExtra with an NSStatusItem handling both mouse buttons.
Use immutable profiles and source bindings in one atomic proxies.json file.
Source-bound Copilot HTTP pools include auth refresh and metadata; Azure applies
the same source choice to Responses HTTP and token-acquisition subprocesses.
Account-only operations have an explicit independent choice. Reject dangling
bindings and referenced-profile deletion. Migrate legacy desktop settings once.

Time series use half-open local calendar intervals, request-only totals, empty
buckets and source filtering; retain missing-usage disclosures and separate
remote Copilot quota. No telemetry includes prompt bodies or credentials.
